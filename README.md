## About

I'm a Computer Science student based in Brazil, learning through
practical projects and sharing the process here.

Currently building **GitMetrics**, a command-line tool that brings
GitHub profiles, repository metrics, and contribution activity
to the terminal.

I care about readable code, useful documentation, and understanding
the decisions behind what I build.

## Featured project

### [`> GitMetrics`](https://github.com/urlastkizz/GitMetrics)

Explore GitHub without leaving your terminal.

- Look up public profiles and repositories.
- Explore repository metrics and contribution activity.
- Export results as JSON for scripts and other tools.

**Try it:**

```sh
npx @urlastkizz/gitmetrics repo microsoft/vscode
```
